# 匈牙利节假日（简体中文）

适用于 Apple 日历的中文 iCalendar 订阅源，包含 2026–2035 年法定节日和已公布的 2026 年调休安排。

订阅地址（GitHub Pages 启用后）：

https://chayiha.github.io/hungary-holidays-zh/hungary-holidays-zh.ics

**注意**：这是独立编制的中文日历，不是苹果原始节日源的实时翻译。未来政府公布的调休安排需要人工更新规则；每月重建本身不能发现新法令。

使用：iPhone 日历 → 日历 → 添加日历 → 添加订阅日历 → 输入上述 URL。

依据：匈牙利劳动法第 102 条和 [2026 年调休法令 10/2025 (IV.30.) NGM](https://net.jogtar.hu/jogszabaly?docid=A2500010.NGM)。
